# Символьные и строковые константы в C

**Тема:** Одинарные и двойные кавычки в языке C  
**Раздел:** Основы языка C

---

## 1. Главное правило

| Запись | Что это | Пример |
|--------|---------|--------|
| `'A'` | **Символьная константа** (один символ) | `char c = 'A';` |
| `"A"` | **Строковый литерал** (строка) | `char *s = "A";` |

**Одинарные кавычки — один символ.**  
**Двойные кавычки — строка символов.**

⚠️ **Это разные типы данных.** Их нельзя путать.

---

## 2. Символьная константа — `'A'`

### 2.1. Что это

**Символьная константа** — это **один символ** в одинарных кавычках.

```c
char c = 'A';
```

**Тип:** `char` (1 байт).  
**Значение:** код символа в таблице ASCII.

**Пример:**

```c
char c = 'A';
printf("%c\n", c);   // A
printf("%d\n", c);   // 65 (ASCII-код)
```

### 2.2. В памяти

```
Переменная c (1 байт)
┌─────┐
│ 'A' │  = 65 в ASCII
└─────┘
```

### 2.3. Что можно хранить

```c
char c1 = 'A';      // буква
char c2 = '5';      // цифра (символ, не число!)
char c3 = ' ';      // пробел
char c4 = '\n';     // перевод строки
char c5 = '\t';     // табуляция
char c6 = '\\';     // обратный слэш
char c7 = '\'';     // одинарная кавычка
```

⚠️ **Только один символ.** `'AB'` — ошибка.

### 2.4. Управляющие последовательности

| Запись | Что означает |
|--------|--------------|
| `'\n'` | Перевод строки |
| `'\t'` | Табуляция |
| `'\r'` | Возврат каретки |
| `'\\'` | Обратный слэш |
| `'\''` | Одинарная кавычка |
| `'\0'` | Нулевой символ |
| `'\a'` | Звуковой сигнал |

---

## 3. Строковый литерал — `"A"`

### 3.1. Что это

**Строковый литерал** — это **последовательность символов** в двойных кавычках.

```c
char *s = "A";
```

**Тип:** `const char *` (указатель на первый символ).  
**Размер:** длина строки + 1 (для `'\0'`).

### 3.2. В памяти

⚠️ **Ключевой момент:** строка **всегда заканчивается `'\0'`**.

```c
char *s = "A";
```

**В памяти:**

```
Индекс: 0    1
      ┌────┬────┐
      │ 'A'│'\0'│
      └────┴────┘
```

- `'A'` — символ.
- `'\0'` — **нулевой символ**, маркер конца строки.
- Строка `"A"` занимает **2 байта**, а не 1.

### 3.3. Сравнение с символьной константой

| Запись | Размер | Что содержит |
|--------|:------:|--------------|
| `'A'` | 1 байт | Только `'A'` |
| `"A"` | 2 байта | `'A'` + `'\0'` |

⚠️ **`"A"` ≠ `'A'`.** Это **разные вещи**.

### 3.4. Пример

```c
printf("%c\n", 'A');   // A
printf("%s\n", "A");   // A
printf("%d\n", 'A');   // 65
printf("%d\n", "A");   // адрес в памяти (указатель)
```

⚠️ **`printf("%d", "A")`** выведет **адрес**, а не код символа. Потому что `"A"` — это **указатель**, а `'A'` — **число**.

---

## 4. Схема: как это выглядит в памяти

```c
char c = 'A';
char *s = "A";
```

**Память:**

```
Переменная c (стек)              Строковый литерал (read-only)
┌─────┐                         ┌────┬────┐
│ 'A' │                         │ 'A'│'\0'│
└─────┘                         └────┴────┘
                                    ↑
                                    │
Переменная s (стек)                 │
┌─────────┐                         │
│ адрес ──┼─────────────────────────┘
└─────────┘
```

- `c` — **сам символ** (1 байт на стеке).
- `s` — **указатель** (8 байт на стеке), указывает на строку в read-only.

## 5. Типичные ошибки

### 5.1. Путаница кавычек

```c
printf("%c\n", "A");   // ❌ undefined behavior
```

**Почему плохо:** `%c` ожидает **символ** (`int`), а передали **указатель** (`char *`).

**Правильно:**

```c
printf("%c\n", 'A');   // ✅ A
```

### 5.2. Много символов в одинарных кавычках

```c
char c = 'AB';   // ❌ ошибка
```

**Правильно:**

```c
char c = 'A';       // один символ
char *s = "AB";     // строка
```

### 5.3. Изменение строкового литерала

```c
char *s = "Hello";
s[0] = 'h';   // ❌ Segmentation fault
```

**Почему:** литералы — read-only.

**Правильно:**

```c
char s[] = "Hello";   // массив — можно менять
s[0] = 'h';           // ✅
```

### 5.4. Забыли `'\0'`

```c
char s[3] = {'a', 'b', 'c'};   // ❌ нет '\0'
printf("%s\n", s);              // мусор после 'c'
```

**Правильно:**

```c
char s[4] = {'a', 'b', 'c', '\0'};   // ✅
printf("%s\n", s);                    // abc
```

### 5.5. Сравнение символа и строки

```c
if (c == "A")   // ❌ сравнение числа с указателем
```

**Правильно:**

```c
if (c == 'A')   // ✅
```

## 6. Функции и типы

### 6.1. Что принимают функции

| Функция | Ожидает | Пример |
|---------|---------|--------|
| `printf("%c", ...)` | `int` (символ) | `'A'` |
| `printf("%s", ...)` | `char *` (строка) | `"A"` |
| `putchar(...)` | `int` (символ) | `'A'` |
| `puts(...)` | `char *` (строка) | `"A"` |
| `strlen(...)` | `char *` (строка) | `"A"` |
| `strchr(...)` | `char *` + `int` | `"A", 'A'` |

### 6.2. Пример

```c
char c = 'A';
char *s = "A";

putchar(c);        // A
puts(s);           // A
printf("%zu\n", strlen(s));   // 1
```

## 7. ASCII-коды: почему `'A'` = 65

**ASCII** (American Standard Code for Information Interchange) — таблица, где каждому символу соответствует число.

| Символ | Код |
|--------|:---:|
| `'0'` | 48 |
| `'9'` | 57 |
| `'A'` | 65 |
| `'Z'` | 90 |
| `'a'` | 97 |
| `'z'` | 122 |
| `' '` | 32 |
| `'\n'` | 10 |
| `'\0'` | 0 |

**Полезные факты:**
- `'A' + 1 = 'B'`
- `'a' - 'A' = 32` (разница между регистрами)
- `'0' + 5 = '5'` — можно получать цифры

**Пример:**

```c
char c = 'A';
printf("%c\n", c + 1);   // B
printf("%c\n", c + 2);   // C
```

## 8. Практические примеры

### 8.1. Проверка, является ли символ цифрой

```c
char c = '5';

if (c >= '0' && c <= '9') {
    printf("Это цифра\n");
}
```

### 8.2. Преобразование символа в число

```c
char c = '5';
int n = c - '0';   // 5
printf("%d\n", n);
```

### 8.3. Преобразование числа в символ

```c
int n = 7;
char c = n + '0';   // '7'
printf("%c\n", c);
```

### 8.4. Перевод в верхний регистр

```c
char c = 'a';
if (c >= 'a' && c <= 'z') {
    c = c - 'a' + 'A';   // 'A'
}
printf("%c\n", c);
```

## 9. Итоги

| Что | Запись | Тип | Размер |
|-----|:------:|-----|:------:|
| Символ | `'A'` | `char` | 1 байт |
| Строка | `"A"` | `const char *` | 2 байта (с `'\0'`) |

**Правила:**
1. **Одинарные кавычки** — **один** символ.
2. **Двойные кавычки** — **строка** (с `'\0'` в конце).
3. **`'A'` ≠ `"A"`** — разные типы.
4. **`%c`** — для символа.
5. **`%s`** — для строки.
6. **`'A'` = 65** в ASCII.
7. **Литералы — read-only.**
