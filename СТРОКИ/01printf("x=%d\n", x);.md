# Разбор строки `printf("x=%d\n", x);`

Разберу **посимвольно**, как это читается и что происходит при выполнении.

---

## 1. Общий вид

```c
printf("x=%d\n", x);
```

**Произношение:**
> «Принт-эф: вывести строку "икс равно процент-д", подставив значение переменной `x`, затем перевод строки».

---

## 2. Разбор по частям

| Часть | Что означает | Как читать |
|-------|--------------|-----------|
| `printf` | Функция **форматированного вывода** | «принт-эф» |
| `(` | Открывающая скобка — начало аргументов | — |
| `"x=%d\n"` | **Строка формата** | «икс равно процент-д, обратный слэш-эн» |
| `,` | Разделитель аргументов | «запятая» |
| `x` | **Переменная**, значение которой подставится | «икс» |
| `)` | Закрывающая скобка | — |
| `;` | Конец инструкции | «точка с запятой» |

---

## 3. Что находится внутри строки `"x=%d\n"`

Строка — это **шаблон вывода**. Она содержит:

| Символы | Что означает |
|---------|--------------|
| `x` | Обычный символ — выводится как есть |
| `=` | Обычный символ — выводится как есть |
| `%d` | **Спецификатор формата** — «вставь сюда целое число» |
| `\n` | **Управляющий символ** — «перевод строки» |

⚠️ **Важно:** `%d` и `\n` — это **не текст**, а **управляющие последовательности**. Они не выводятся буквально, а выполняют действия.

---

## 4. Что делает `%d`

**`%d`** — спецификатор формата для **целого числа** (d = decimal, десятичное).

Когда `printf` встречает `%d`, он:
1. Смотрит на **следующий аргумент** после строки формата.
2. Берёт значение этого аргумента (в нашем случае `x`).
3. **Подставляет** его вместо `%d`.

**Пример:**

```c
int x = 5;
printf("x=%d\n", x);
```

**Что происходит:**
- В строке `"x=%d\n"` символы `x` и `=` выводятся как есть.
- Вместо `%d` подставляется `5`.
- `\n` — курсор переходит на новую строку.

**Результат на экране:**

```
x=5
```

---

## 5. Что делает `\n`

**`\n`** — **escape-последовательность** (управляющий символ), означающая **перевод строки** (newline).

| Последовательность | Что означает |
|--------------------|--------------|
| `\n` | Перевод строки |
| `\t` | Табуляция |
| `\\` | Обратный слэш `\` |
| `\"` | Двойная кавычка `"` |
| `%%` | Знак процента `%` |

**Без `\n`:**

```c
printf("x=%d", x);
printf("y=%d", y);
```

**Вывод:**

```
x=5y=7
```

(всё в одной строке — неудобно)

**С `\n`:**

```c
printf("x=%d\n", x);
printf("y=%d\n", y);
```

**Вывод:**

```
x=5
y=7
```

(каждое значение на своей строке)

## 6. Полный пример работы

```c
#include <stdio.h>

int main(void)
{
    int x = 5;
    printf("x=%d\n", x);
    return 0;
}
```

**Пошагово:**

| Шаг | Что происходит |
|:---:|----------------|
| 1 | Создаётся переменная `x = 5` |
| 2 | Вызывается `printf` |
| 3 | `printf` читает строку формата `"x=%d\n"` |
| 4 | Видит `x` → выводит `x` |
| 5 | Видит `=` → выводит `=` |
| 6 | Видит `%d` → подставляет `5` |
| 7 | Видит `\n` → переводит курсор на новую строку |
| 8 | Программа завершается |

**На экране:**

```
x=5
```

---

## 7. Схема подстановки

```
Строка формата:   "x=%d\n"
                   │ │ │
                   │ │ └─── управляющий символ (перевод строки)
                   │ └───── спецификатор формата (целое число)
                   └─────── обычный символ

Аргументы:        x = 5
                    │
                    └─────── подставляется вместо %d

Результат:        "x=5\n"
                   ↓
На экране:        x=5
```

## 8. Частые ошибки

| Ошибка | Что не так | Правильно |
|--------|-----------|-----------|
| `printf("x=%d\n");` | Забыли аргумент `x` | `printf("x=%d\n", x);` |
| `printf("x=%d\n", &x);` | Передали **адрес**, а не значение | `printf("x=%d\n", x);` |
| `printf("x=%s\n", x);` | `%s` для строк, а `x` — число | `printf("x=%d\n", x);` |
| `printf("x=%d\n", "x");` | Передали строку вместо числа | `printf("x=%d\n", x);` |
| `printf("x=%d\n", x, y);` | Лишний аргумент | `printf("x=%d\n", x);` |
| `printf("x=%d\n", x` | Забыли `)` и `;` | `printf("x=%d\n", x);` |

---

## 9. Разные варианты вывода

| Код | Вывод (при `x = 5`) |
|-----|---------------------|
| `printf("%d", x);` | `5` |
| `printf("x=%d", x);` | `x=5` |
| `printf("x=%d\n", x);` | `x=5` + перевод строки |
| `printf("x = %d\n", x);` | `x = 5` + перевод строки |
| `printf("x=%d, y=%d\n", x, y);` | `x=5, y=7` + перевод строки |
| `printf("x=%5d\n", x);` | `x=    5` (ширина 5) |
| `printf("x=%-5d\n", x);` | `x=5    ` (выравнивание влево) |
| `printf("x=%05d\n", x);` | `x=00005` (нули слева) |

## 10. Спецификаторы формата

| Спецификатор | Для какого типа |
|--------------|-----------------|
| `%d`, `%i` | `int` (целое) |
| `%u` | `unsigned int` |
| `%f` | `float`, `double` |
| `%lf` | `double` (в `scanf`) |
| `%c` | `char` (символ) |
| `%s` | строка |
| `%p` | указатель |
| `%x`, `%X` | шестнадцатеричное |
| `%o` | восьмеричное |
| `%%` | сам символ `%` |

## 11. Итог

**Строка:**

```c
printf("x=%d\n", x);
```

**Что делает:**
1. Выводит **`x=`** (обычные символы).
2. Вместо **`%d`** подставляет **значение `x`**.
3. **`\n`** переводит курсор на новую строку.

**Результат при `x = 5`:**

```
x=5
```

**Читается как:**
> «Напечатай: "икс равно", затем значение x, затем перевод строки».
