# Разбор программы с функцией `foo`

Разберу код **построчно**: что такое прототип, реализация, вызов, и что происходит в памяти.

---

## 1. Полный код

```c
float foo (float x, int n); // прототип

float foo (float x, int n)  // реализация
{
    float res;
    res = x * n;
    return res;
}

int main ( )
{
    float z;
    z = foo (3.5, -10);     // вызов
    return 0;
}
```

---

## 2. Что такое прототип

**Строка 1:**

```c
float foo (float x, int n);
```

**Прототип функции** — это **объявление** функции **без тела**.

**Что он сообщает компилятору:**
- Имя функции: `foo`.
- Тип возвращаемого значения: `float`.
- Параметры: `float x`, `int n`.
- Что функция **будет определена** где-то ниже.

⚠️ **Зачем нужен прототип:**
- Компилятор **знает** о функции **до** её использования.
- Может **проверить типы** аргументов при вызове.
- Позволяет вызывать функцию **до** её определения.

**Синтаксис:**

```
возвращаемый_тип имя (тип1 параметр1, тип2 параметр2, ...);
```

⚠️ **В конце — точка с запятой.** Это **объявление**, а не определение.

---

## 3. Реализация функции

**Строки 3–8:**

```c
float foo (float x, int n)  // реализация
{
    float res;
    res = x * n;
    return res;
}
```

**Реализация (определение)** — это **сама функция** с телом.

**Разбор:**

| Строка | Что делает |
|--------|-----------|
| `float foo (float x, int n)` | **Заголовок функции**: возвращает `float`, принимает `float x` и `int n` |
| `{` | Начало тела |
| `float res;` | Объявление **локальной** переменной `res` типа `float` |
| `res = x * n;` | Умножаем `x` на `n`, результат в `res` |
| `return res;` | Возвращаем `res` |
| `}` | Конец тела |

⚠️ **Заголовок без `;`** — это уже **определение**.

**Схема работы:**

```
Вход: x = 3.5, n = -10
       ↓
res = x * n = 3.5 * (-10) = -35.0
       ↓
return -35.0
```

---

## 4. Функция `main`

**Строки 10–15:**

```c
int main ( )
{
    float z;
    z = foo (3.5, -10);     // вызов
    return 0;
}
```

**Разбор:**

| Строка | Что делает |
|--------|-----------|
| `int main ( )` | Главная функция, возвращает `int` |
| `{` | Начало тела |
| `float z;` | Объявление переменной `z` типа `float` |
| `z = foo (3.5, -10);` | **Вызов** функции `foo` с аргументами |
| `return 0;` | Возврат 0 — успешное завершение |
| `}` | Конец `main` |

---

## 5. Что такое вызов функции

**Строка 13:**

```c
z = foo (3.5, -10);
```

**Что происходит:**

1. Компилятор **видит** вызов `foo`.
2. **Проверяет** по прототипу:
   - первый аргумент `3.5` → должен быть `float` → ✅ `3.5` — это `double`, но приводится к `float`.
   - второй аргумент `-10` → должен быть `int` → ✅ `-10` — это `int`.
3. **Передаёт** значения в функцию.
4. Функция **выполняется**.
5. **Возвращает** результат.
6. Результат **присваивается** переменной `z`.

---

## 6. Схема работы программы

```
┌──────────────────────────────────────────────┐
│  main()                                      │
│                                              │
│  float z;                                    │
│                                              │
│  z = foo(3.5, -10);                          │
│         │                                    │
│         ▼                                    │
│  ┌─────────────────────────────────────┐    │
│  │  foo(x = 3.5, n = -10)              │    │
│  │                                     │    │
│  │  res = x * n                        │    │
│  │  res = 3.5 * (-10) = -35.0          │    │
│  │                                     │    │
│  │  return -35.0                       │    │
│  └─────────────────────────────────────┘    │
│         │                                    │
│         ▼                                    │
│  z = -35.0                                   │
│                                              │
│  return 0;                                   │
└──────────────────────────────────────────────┘
```

---

## 7. Что происходит в памяти

**Перед вызовом:**

```
Стек main:
┌──────────┐
│ z = ?    │ (мусор)
└──────────┘
```

**Во время вызова:**

```
Стек main:                Стек foo:
┌──────────┐             ┌──────────┐
│ z = ?    │             │ x = 3.5  │
└──────────┘             │ n = -10  │
                         │ res = ?  │
                         └──────────┘
```

**После вычисления:**

```
Стек main:                Стек foo:
┌──────────┐             ┌──────────┐
│ z = ?    │             │ x = 3.5  │
└──────────┘             │ n = -10  │
                         │ res = -35│
                         └──────────┘
```

**После возврата:**

```
Стек main:
┌──────────┐
│ z = -35  │
└──────────┘

Стек foo: уничтожен (x, n, res исчезли)
```

⚠️ **Локальные переменные `x`, `n`, `res` живут только внутри `foo`.**

---

## 8. Что если убрать прототип

```c
// float foo (float x, int n);  // убрали

float foo (float x, int n)
{
    ...
}
```

**Что произойдёт:**
- Если **определение стоит до** `main` — всё работает.
- Если **определение стоит после** `main` — **ошибка компиляции**: компилятор не знает о `foo`, когда встречает вызов.

**Правило:**
> **Если функция используется до её определения — нужен прототип.**

---

## 9. Что если типы не совпадают

```c
z = foo(3.5, -10);      // ✅ 3.5 → float, -10 → int
z = foo(3.5, 2.5);      // ⚠️ 2.5 → int (2) — потеря данных
z = foo("hello", 5);    // ❌ ошибка компиляции
```

**Правило:** компилятор **проверяет типы** по прототипу.

---

## 10. Что произойдёт при вызове

**Пример:**

```c
z = foo(3.5, -10);
```

**Пошагово:**

| Шаг | Что происходит |
|:---:|----------------|
| 1 | В `foo` передаются значения: `x = 3.5`, `n = -10` |
| 2 | `res = x * n = 3.5 * (-10) = -35.0` |
| 3 | `return res;` возвращает `-35.0` |
| 4 | Результат присваивается `z` |
| 5 | `z = -35.0` |

**Вывод на экран ничего нет** — программа ничего не печатает.

---

## 11. Что если добавить `printf`

```c
int main()
{
    float z;
    z = foo(3.5, -10);
    printf("z = %f\n", z);   // z = -35.000000
    return 0;
}
```

**Вывод:**

```
z = -35.000000
```

⚠️ `%f` выводит `float` с 6 знаками после запятой по умолчанию.

**С точностью 1 знак:**

```c
printf("z = %.1f\n", z);   // z = -35.0
```

## 12. Итоги

| Часть | Что это | Пример |
|-------|---------|--------|
| **Прототип** | Объявление функции | `float foo(float x, int n);` |
| **Реализация** | Сама функция | `float foo(float x, int n) { ... }` |
| **Вызов** | Использование функции | `z = foo(3.5, -10);` |

**Что важно:**
1. **Прототип** говорит компилятору о функции **до** её использования.
2. **Реализация** содержит **тело** функции.
3. **Вызов** передаёт аргументы и получает результат.
4. **Локальные переменные** функции живут только внутри неё.
5. **Типы аргументов** проверяются по прототипу.
